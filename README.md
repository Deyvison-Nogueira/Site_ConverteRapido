O que o app faz: Uma aplicação web em formato de painel que permite a conversão rápida de várias unidades (Moeda, Comprimento, Volume, Massa, Área e Velocidade).



Como rodar: Basta abrir a pasta do projeto no VS Code e utilizar a extensão Live Server, ou rodar o comando python -m http.server 8000 no terminal e aceder a http://localhost:8000 no navegador.



Uso de IA: O Gemini foi utilizado como assistente para estruturar os requisitos textuais da proposta, otimizar a lógica matemática evitando repetição de código (Clean Code) e formatar o layout CSS em formato de grelha responsiva.
